Responsive Design
-----------------

The portfolio was designed to adapt to different screen sizes.

On desktop devices, sections can take advantage of additional horizontal space to display content side by side.

On tablets and mobile devices, the layout changes to a primarily vertical structure so content remains readable without requiring horizontal scrolling.

Responsive adjustments include:

-   Stacking multi-column layouts vertically

-   Resizing images and icons

-   Adapting typography for smaller screens

-   Making cards use the available screen width

-   Reorganizing the About section for mobile

-   Resizing animated elements

-   Making forms mobile-friendly

-   Preventing horizontal page overflow

Responsive Development
----------------------

One of the main improvements made to this project was replacing fixed positioning and screen-specific spacing with layouts that adapt naturally to the available viewport.

The portfolio uses techniques including:

```
display: flex;
display: grid;
flex-direction: column;
max-width: 100%;
height: auto;
box-sizing: border-box;

```

along with CSS media queries for smaller screens.

This allows the website to remain usable across desktop and mobile devices while maintaining the original visual style of the portfolio.
